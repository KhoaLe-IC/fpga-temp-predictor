# Implementation status — 28 October 2026

Both versions and both architectures passed physical DE2 JTAG replay: temperature speed/resource and weather parallel/shared. Each accepted 128 samples and produced 104 checked forecasts. All four original core SDF timing simulations passed at 50 MHz.

See [JTAG implementation results](JTAG_IMPLEMENTATION_REPORT.md) and [defense evidence status](DEFENSE_EVIDENCE_STATUS.md). Physical UART operation remains untested. SignalTap waveform acquisition and the final defense evidence package are being completed separately; the functional hardware passes do not prove those deliverables complete.
