## Design decisions

A warm light canvas alternates with dark ink for major hardware concepts. Roboto Condensed provides compact headings and large quantitative emphasis. Roboto supplies body labels. Teal marks the selected model and current hardware result; amber distinguishes the direction-conversion stage and held-out test period.

The composition varies by subject. Forecast timing uses a large numeral and clock-time relationship. Data preparation uses a time-proportional split. The arithmetic schedule uses duration bars. Accuracy retains five native editable charts with separate units and scales. Quartus and SignalTap records remain original embedded screenshot files with no displayed values altered.

The weather cover is a generated atmospheric illustration. It is not experimental evidence or a photograph of a project session. The speaker notes retain that provenance. All implementation evidence uses saved native application captures.

The superseded storyboard's uniform headline and white-background instructions describe the earlier version. This revision changes visual direction in response to the request for a substantial professional redesign. Technical scope, 14-minute-15-second speaking plan, evidence boundaries, and hidden backup content remain in force.
