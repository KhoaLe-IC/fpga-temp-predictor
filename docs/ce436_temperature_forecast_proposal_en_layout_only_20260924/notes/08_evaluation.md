Our first question is whether the forecast improves on simple alternatives: the current temperature and the same-hour value from the previous day. We will compare all methods on the same test timestamps using mean absolute error in degrees Celsius. Our second question is whether the hardware follows its specification: we compare floating point with fixed point, then require RTL to match the fixed-point reference bit for bit at the correct valid cycle. LUT, flip-flop, DSP, and latency figures will come from synthesis rather than estimates.
