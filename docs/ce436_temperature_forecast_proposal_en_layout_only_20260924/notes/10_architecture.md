The FPGA accepts a new sample only when valid is asserted. It stores twenty-five samples so it can read the four required time indices, forms two differences, multiplies them by the fixed coefficients, and adds the anchor and offset. The diagram describes functions, not a final choice between shared and parallel multipliers. A delay of one sample represents one hour in the data sequence, whereas hardware latency is measured in clock cycles; the circuit does not wait three real hours to forecast.
